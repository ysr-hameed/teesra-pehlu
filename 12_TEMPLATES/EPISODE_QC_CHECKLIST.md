# Episode Quality Checklist

## Story
- [ ] Strong opening hook
- [ ] Clear mystery
- [ ] Believable suspects
- [ ] Fair clues
- [ ] Logical reveal
- [ ] No major plot holes

## Visuals
- [ ] Consistent faces
- [ ] Consistent locations
- [ ] Consistent art style
- [ ] Correct scene order
- [ ] No unwanted duplicate characters

## Audio
- [ ] Natural Hindi voices
- [ ] Correct pronunciation
- [ ] Clear dialogue
- [ ] Balanced sound effects
- [ ] Music does not overpower dialogue

## Publishing
- [ ] Correct aspect ratio
- [ ] Thumbnail ready
- [ ] Title and description ready
- [ ] Fiction label included
- [ ] Final export reviewed
