# Visual Style Guide

Premium cinematic Japanese-inspired 2D anime thriller.
Realistic Indian facial anatomy and proportions.
Clean line art, sophisticated cel shading, subtle painterly rendering.

Palette: muted teal, slate grey, deep indigo and warm amber accents.
Format: 16:9 widescreen.

Use purposeful establishing shots, character close-ups, controlled camera movement and cinematic depth.

Avoid Pixar-like 3D, CGI, chibi proportions, exaggerated anime eyes, random character redesigns and generic slideshow compositions.
Always use approved character references.
